## How to Post on GitHub

1. Go to **[New Issue](https://github.com/Darwin27264/ofln/issues/new)**.
2. Copy the title and markdown content from the relevant `.md` file in this directory.
3. Add the suggested GitHub labels (e.g., `good first issue`, `enhancement`, `help wanted`).
4. Click **Submit new issue**.
